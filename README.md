# 抖音

把抖音网页版装进一个干净的桌面窗口，并内置「抖音优化」用户脚本：视频过滤、屏蔽登录弹窗、
自定义清晰度、禁止自动播放、自动进入全屏、屏蔽弹幕和礼物特效等。

> 维护者 / AI agent 请看 [AGENTS.md](AGENTS.md)：项目结构、约定、测试与排查手册都在那里。

## 下载

从 [Releases](https://github.com/yhgeo/douyin-desktop/releases) 下载便携版 `抖音 x.y.z.exe`，双击即可运行，
**不需要安装**。本仓库不再构建安装版。

- 便携版会先解压到 `%TEMP%` 再运行，这是 electron-builder 便携目标的行为，不是安装。
- 想放在固定目录、什么都不解压，可以直接用构建产物里的 `win-unpacked/` 文件夹。

> 与 `npm start` 共用同一份配置（`%APPDATA%\douyin-desktop`），所以登录态与脚本配置是通用的。
> 也正因为共用，**不要同时运行两个**。

## 已集成

- `https://www.douyin.com/` 独立桌面窗口
- 登录状态、Cookie 和本地存储持久化
- 前进、后退、刷新、主页、开发者工具
- 内置抖音优化脚本及其依赖
- 尽可能兼容脚本使用的 GM 存储、请求、下载和菜单 API
- 本地「抖音优化」启用/禁用开关与完整配置界面入口
- 全中文桌面菜单、抖音应用名称与图标
- 拦截 `bytedance://` 等未安装的外部协议，避免 Windows 弹出“选择应用”窗口
- 分别清除「抖音网页数据」与「脚本配置数据」，两者互不影响
- 脚本配置支持导出到文件 / 从文件导入，便于备份与恢复
- Electron Builder Windows 安装版与便携版构建配置

## 使用

| 菜单 | 内容 |
| --- | --- |
| 导航 | 抖音首页、后退 / 前进、刷新 |
| 抖音优化 | 启用 / 禁用脚本、打开配置界面（`Ctrl+,`）、移动端配置、导出 / 导入配置，以及脚本自己注册的菜单项 |
| 视图 | 放大 / 缩小 / 恢复缩放、全屏 |
| 工具 | 开发者工具、**关闭卡住的弹窗**、**修复无法加载的页面**、**打开运行日志**、清除抖音网页数据、清除脚本配置数据、退出 |

脚本配置的导入导出会读写一个 JSON 文件，可以自己编辑，也方便换机器。

## 遇到问题

### 窗口黑屏，一直加载不出来

先点 **工具 → 修复无法加载的页面**：它会清掉站点的非登录数据并重新加载，**登录态保留**。

多数情况下应用会**自己修好**，不用你动手：检测到页面为空就按阶梯处理（清站点数据 → 清反爬 cookie →
清缓存 → 逐步延长间隔重试），窗口标题会显示「正在自动修复（第 N 次）」。

### 窗口标题显示「服务器暂时没有返回页面」

说明服务器端没有给页面，而不是本地坏了。重试间隔会自动放长（最长 5 分钟），
**不要反复重启**——每一次重启都是一次新请求，反而会让服务器更不愿意响应。等几分钟即可。

### 窗口标题显示「服务器要求人机验证」

抖音侧要求完成一次人机验证（通常是短时间内请求过于频繁导致的）。这种情况**清数据、重装都没有用**，
等几分钟再打开即可。

提示会在页面恢复可用后**自动消失**；应用只在服务器确实要求验证时才显示它。

### 弹窗点不动了

「是否保存登录信息？」这类弹窗偶尔会卡在按钮转圈的状态，整页点不动。应用会在约 1 秒内自动关掉它，
也可以手动 **工具 → 关闭卡住的弹窗**。

### 双击后一闪而过，窗口起不来

这是 Chromium 的 GPU 子进程无法启动，导致主进程主动中止 —— 与应用逻辑无关。
可以先用 `npm start -- --in-process-gpu` 启动，或重启机器。详见 [AGENTS.md](AGENTS.md)。

### 想反馈问题

**工具 → 打开运行日志**，第一行记录了版本、运行方式（便携版 / 开发）与配置目录，
连同日志一起提供会省很多时间。

## 脚本来源与许可

内置脚本来自 `WhiteSevs/TamperMonkeyScript`，脚本标注为 **GPL-3.0-only**。对应脚本源码保存在：

- `assets/douyin-optimization.user.js`

其依赖的 UMD 文件保存在：

- `vendor/`

更新脚本前请阅读并遵循上游项目的许可和发布要求。
