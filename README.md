# 抖音（桌面版）

把抖音网页版装进一个干净的桌面窗口，并内置「抖音优化」用户脚本：视频过滤、屏蔽登录弹窗、
自定义清晰度、禁止自动播放、自动进入全屏、屏蔽弹幕与礼物特效等。

> 维护者与 AI agent 请看 [AGENTS.md](AGENTS.md) —— 项目结构、约定、测试与排查手册都在那里。

## 下载

从 [Releases](https://github.com/yhgeo/douyin-desktop/releases) 下载，有两个版本：

| 文件 | 说明 |
| --- | --- |
| `x.y.z-setup.exe` | **安装版（推荐）**。单用户安装，不需要管理员，可以自选安装目录。启动快。 |
| `x.y.z.exe` | 便携版。单文件，双击即用，不需要安装；但**每次启动都要自解压**。 |

**两者启动速度差很多**（实测，同一份代码）：

| 从双击到 | 便携版 | 安装版（首次） | 安装版（之后每次） |
| --- | --- | --- | --- |
| 应用就绪 | 约 15.7 秒 | 约 2.8 秒 | **约 0.3 秒** |
| 页面加载完成 | 约 20.5 秒 | 约 9.9 秒 | **约 6 秒** |

便携版慢的原因：它是个自解压包，每次启动都把整个程序（约 470 MB）解压到 `%TEMP%` 的随机目录，
从那里运行，退出时再删掉。安装版把文件放在固定位置，启动时直接读。

安装版**首次**启动慢一些，是因为 Windows Defender 要扫描刚写入的文件；之后就是热启动。
便携版没有"之后" —— 它每次解出来的都是新文件。

> 「应用就绪」那一行才是打包方式决定的；「页面加载完成」还要加上抖音网页自身的加载时间，
> 会随网络波动，不要拿它比较版本。

> 想放到 U 盘里带着用、或者不想安装，选便携版；在意启动速度，选安装版。

窗口打开后先是 logo 加「正在加载…」，随后换成抖音网页版 —— 这一步是正常的，不是卡住。

## 第一次使用

1. 双击运行，窗口打开抖音网页版；用扫码或短信登录（登录状态会保留）。
2. 顶部菜单 **抖音优化** 可以启用 / 停用脚本、打开配置界面（`Ctrl+,`），以及导出 / 导入配置。

## 包含什么

- 独立的抖音桌面窗口，登录状态、Cookie 与网页数据持久化
- 前进 / 后退 / 刷新 / 主页 / 缩放 / 全屏
- 内置「抖音优化」脚本及其依赖，尽量兼容脚本用到的 GM 存储、请求、下载与菜单 API
- 全中文菜单、应用名与图标
- 拦截 `bytedance://` 等未安装的外部协议，避免 Windows 弹出"选择应用"窗口
- 「抖音网页数据」与「脚本配置数据」可以分别清除，互不影响
- 脚本配置支持导出到文件 / 从文件导入，便于备份与换机器

## 菜单一览

## 遇到问题

**窗口黑屏，一直加载不出来**

正常加载时窗口会显示 logo 和「正在加载…」。如果**一直是纯黑、没有任何文字**，那才是出问题了：
先点 **工具 → 修复无法加载的页面**：清掉网页的临时数据后重新加载，**不会掉登录**。
多数情况应用会自己修好 —— 检测到页面为空就自动按阶梯重试，窗口标题会显示「正在自动修复（第 N 次）」。

**窗口标题显示「服务器暂时没有返回页面」**

服务器端没给页面，不是本地坏了。重试间隔会自动放长（最长 5 分钟）。
**不要反复重启** —— 每次重启都是一次新请求，反而让服务器更不愿意响应。等几分钟即可。

**窗口标题显示「服务器要求人机验证」**

抖音要求完成一次人机验证（通常是短时间内请求过于频繁）。清数据、重装都没有用，等几分钟再打开。
提示会在页面恢复可用后自动消失；应用只在服务器确实要求验证时才显示它。

**弹窗点不动了**

「是否保存登录信息？」这类弹窗偶尔会卡在按钮转圈的状态，整页点不动。
应用会在约 1 秒内自动关掉它，也可以手动 **工具 → 关闭卡住的弹窗**。

**双击后一闪而过，窗口起不来**

Chromium 的 GPU 子进程启动失败导致主进程中止，与应用逻辑无关。重启机器一般即可恢复；
用 `npm start` 运行的话可以先加 `--in-process-gpu`。

**想反馈问题**

**工具 → 打开运行日志**，最前面几行记录了版本、运行方式与数据目录；连同日志一起提供会省很多时间。

## 数据放在哪里

登录状态、网页数据、脚本配置、运行日志都在同一个目录里，位置取决于你用的是哪个版本：

| 版本 | 数据目录 |
| --- | --- |
| 安装版 | `<安装目录>\data`（安装时你自己选的那个目录） |
| 便携版 | 便携 exe 旁边的 `data\` |
| 开发运行（`npm start`） | `%APPDATA%\douyin-desktop` |

目录里面的文件：

| 内容 | 文件 |
| --- | --- |
| 登录状态、网页数据 | `data\`（Chromium 的 profile） |
| 脚本配置 | `data\userscript-config.json` |
| 运行日志 | `data\logs\main.log` |

**首次运行安装版或便携版时，如果 `%APPDATA%\douyin-desktop` 里有旧数据，会自动复制一份过去**，
登录状态与脚本配置一并保留（旧目录不会被动）。只复制不可再生的部分，缓存不复制，所以这一步很快。

> **备份就是复制整个 `data` 文件夹。**
> 注意：数据在安装目录里，所以**卸载安装版会连同数据一起删除**；`%APPDATA%\douyin-desktop`
> 里那份旧数据不受卸载影响。

> **同一种运行方式不要开两个。** 安装版、便携版、开发运行各自有独立的数据目录，可以同时开；
> 但同一个版本开第二个会立刻退出，并把已有窗口唤到最前 —— 同一个 profile 被两个进程写会损坏它，
> 登录状态与脚本配置都在那份数据里。

「清除抖音网页数据」只清登录与网页数据（保留脚本配置）；「清除脚本配置数据」只清脚本配置
（保留登录）。想换机器时用「导出配置到文件」。

## 脚本来源与许可

内置脚本来自 `WhiteSevs/TamperMonkeyScript`，标注为 **GPL-3.0-only**。
脚本源码保存在 `assets/douyin-optimization.user.js`，其依赖的 UMD 文件保存在 `vendor/`。
更新脚本前请阅读并遵循上游项目的许可与发布要求。
